# 쿠팡코끼리 앱 배포 체크리스트 (TestFlight)

목표: 서버 개선 사항이 앱 UI/UX에 제대로 반영되도록 “한 번에” 묶어 배포.

## A. 이번에 반드시 포함할 항목(사용자 체감)
1) **409 에러 사유 한국어 표시**
- 서버가 내려주는 `messageKo/hint`를 우선 표시
- 기존처럼 코드만 보여주지 않기

2) **다중 업로드 prefix/suffix 일괄 적용 팝업**
- 다중 업로드는 개별 리네임 팝업 대신 일괄 규칙 적용

3) (옵션) 추천 탭 ‘판단 가능 UI’
- 썸네일 실패 시에도 가격/마진/배송비/키워드가 상단에서 보이게

## B. 배포 전 점검
- [ ] 기본 서버 주소가 `https://app.splui.com` 인지
- [ ] 에러 메시지 표시 우선순위: `messageKo` > `hint` > `message` > `code`
- [ ] 업로드/큐 요청이 실패할 때 재시도 안내 문구 있는지

## C. 배포 후 확인(현호 기기)
- [ ] 다중 업로드 시 409가 떠도 “이유”가 보이는지
- [ ] 다중 업로드 prefix/suffix 팝업 동작
- [ ] 완료/실패 표시가 뒤로 튕기지 않는지

## D. 다음 배포(큐 전환 포함)
- 업로드를 `enqueue → worker`로 강제 전환되면,
  - [ ] 큐 화면(대기/진행/완료/실패) 제공
  - [ ] 취소/재시도 버튼 제공
