# 참고 SaaS: coupilot.net UI/구성 메모 (2026-02-12)

목표: 쿠팡 코끼리(가칭) 웹/대시보드 UX를 coupilot과 유사한 1차 완성본으로 맞추기 위한 레퍼런스 정리.

## 1) 랜딩 페이지 구성(관찰)
- 상단 네비: 로고 + 메뉴(요금제/블로그/문의/…)+ 검색창 + 로그인
- 히어로 섹션:
  - 강한 한 문장 카피(“사업이 막막한 순간, 답은 데이터…”) + CTA 버튼(체험/문의)
  - 우측에 제품 스크린샷 모형 + 작은 팝업 카드(성과/후기 느낌)
- 중간 섹션: 단계형 소개(예: 상품 분석/성과/후기/사례)
- 신뢰 섹션: 사용자/전문가 영상/후기 카드
- 지표 섹션: “결과가 증명합니다” 형태로 숫자 강조
- 후기 섹션: 카드형 캐러셀/그리드
- 푸터: 회사 정보/링크

## 2) 우리 서비스(쿠팡 코끼리)로 매핑(제안)
- 히어로 카피는 ‘추천 상품 자동 업로드/옵션 파싱/가격 최적화/429 회피 캐시’ 같은 핵심 가치 1문장
- CTA 2개:
  1) “바로 시작하기(카카오 로그인)”
  2) “데모 보기(샘플 계정/샘플 데이터)”
- 단계형 섹션(3-step):
  1) 키워드/카테고리 선택
  2) 후보 수집(429 방어 + 캐시)
  3) 추천/업로드(진행률/로그/실패 재시도)
- 신뢰 섹션: 실제 업로드 히스토리/성공률/평균 처리시간(실데이터 기반)

## 3) 구현 우선순위(‘완전히 유사’ 1차)
- 랜딩(정적) + 로그인/온보딩 + 대시보드(추천/진행률)까지 일관된 디자인 시스템
- 추천 탭:
  - ‘지금 채우기(fill)’ 버튼
  - 진행률(phase/progress string)
  - 결과 카드(상품명/가격/옵션 수/원본 링크)
- 운영 안정화:
  - 서버 단일 실행(포트 3000 EADDRINUSE 방지)
  - 429 방어(요청 제한/백오프) 상태 표시
