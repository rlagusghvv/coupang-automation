# Product principles — 쿠팡 코끼리 (2026-02-12)

## 완성의 기준
- **유료로 제공해도 부끄럽지 않은 수준**: 신뢰/안정성이 최우선
- 오류/멈춤/데이터 불일치가 잦으면 서비스 불가 → 기능 추가보다 안정화/관측/복구가 먼저

## 타겟 유저
- 온라인 비즈니스에 관심이 있고 **돈을 벌고 싶은 소규모 셀러**
- 기술에 익숙하지 않을 수 있음 → 용어/UX는 단순해야 함

## 과금/비용 원칙(현 단계)
- 당장 사용자 과금 요소는 넣지 않음
- 서비스 제공자 관점에서도 비용(유료 API/인프라)은 최소화
- 추후 서비스로 수익 구조가 확립되면 그때 비용 투자/확장

## 현재 제품 방향(레퍼런스 활용)
- coupilot 같은 레퍼런스는 “따라하기”가 아니라 **우리 서비스의 부족한 부분을 메우는 기준점**으로 사용
